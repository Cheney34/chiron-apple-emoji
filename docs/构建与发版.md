# 构建与发版

从源码到 `v6.5` 三个产物的完整流程。所有命令都在仓库根目录执行。

## 0. 环境

| 需要 | 版本 | 用途 |
|---|---|---|
| Python | ≥ 3.9 | 字体处理、打包 MTZ |
| `fonttools` `pillow` | 最新 | `pip install fonttools pillow` |
| zip | 任意 | 打 Root 模块 |
| JDK 17 + Android SDK | — | 只有本地构建 LSPosed 才需要，**推荐交给 CI** |

`chiron-font/build_v6.py` 里的默认路径是作者原机器的绝对路径，**别照抄**，一律用命令行参数覆盖。

## 1. 素材

Apple emoji 位图与元数据，一次准备：

```bash
python3 emoji-font/fetch17.py
# -> emoji-font/img/            3946 张 160×160 RGBA PNG
# -> emoji-font/emoji-data.json Emoji 17.0 元数据
```

上游固定在 commit `e77759c2`（`iamcal/emoji-data` master）。npm 上的
`emoji-datasource-apple` 停在 16.0.0，没有 17.0 的图，别再照着老文档 `npm pack`。

Chiron GoRound TC VF 与 Merriweather（300/400/800 三份实例）自备，`chiron-font/README.md` 里有来源。

## 2. 三个产物

### 2.1 emoji 字体（两条通道档位不同）

```bash
cd emoji-font

# KSU / Magisk：三档真彩，约 60 MB
STRIKES=32,45,60 IMGDIR=./img JSONF=./emoji-data.json \
OUT=../build/emoji/ksu.ttf python3 build17.py

# MTZ：单档 128 ppem 真彩，约 92 MB
STRIKES=128 IMGDIR=./img JSONF=./emoji-data.json \
OUT=../build/emoji/mtz.ttf python3 build17.py
```

跑完检查日志里的 `art:` 数字，应该在 **3946** 上下；明显偏少说明素材目录挑错了。

### 2.2 MTZ（整包重做时）

```bash
cd chiron-font
python3 build_v6.py \
    --src-font ../build/mtz/fonts/Roboto-Regular.ttf \
    --emoji    ../build/emoji/mtz.ttf \
    --version  6.5 \
    --out      ../Chiron-Merriweather_v6.5_AppleEmoji.mtz
```

脚本会先打印校验结果再打包。**看到 `!! 规格不合格，拒绝打包` 就停下来**，按提示回去改
`STRIKES` 或重跑 `fix_metrics.py`，不要加 `--force` 绕过——那正是 v6.2 出问题的路径。

### 2.3 只换 emoji（本版用的就是这条）

正文与预览图不该动的时候，不要重跑 2.2，直接把新字体塞回上一版成品：

```bash
python3 tools/repack_emoji.py \
    --base  ../chiron-v6.4/Chiron-Merriweather_v6.4_AppleEmoji.mtz \
    --emoji ../build/emoji/mtz.ttf \
    --kind  mtz --version 6.5 \
    --out   ../chiron-v6.5/Chiron-Merriweather_v6.5_AppleEmoji.mtz

python3 tools/repack_emoji.py \
    --base  ../chiron-v6.4/Chiron_KSU_Font_A17_v6.4.zip \
    --emoji ../build/emoji/ksu.ttf \
    --kind  ksu --version 6.5 \
    --out   ../chiron-v6.5/Chiron_KSU_Font_A17_v6.5.zip
```

它沿用原包所有 `ZipInfo`，只替换 `fonts/NotoColorEmoji.ttf` / `system/fonts/NotoColorEmoji.ttf`
并改版本串；`description.xml` 的描述文字和 KSU `README.md` 的更新日志需要手工补。

### 2.4 Root 模块（magisk-module，仍是 6.2）

```bash
cd magisk-module
mkdir -p system/fonts
cp ../build/emoji/ksu.ttf system/fonts/NotoColorEmoji.ttf
zip -r ../Chiron-Emoji-v6.2-Root.zip . -x '*/.git*'
```

### 2.5 LSPosed APK

不用本地搭 Android SDK。推到 GitHub 后：**Actions → 构建 LSPosed 模块 → Run workflow**，
几分钟后 `lsposed-apk` artifact 里就有 APK。搜狗面板的新版模块在
[apple-input-for-sogou](https://github.com/Cheney34/apple-input-for-sogou)，那边用
`tools/build-apk.ps1`（只需 build-tools + JDK，不需要 Gradle）。

## 3. 发版前自查

```bash
python3 - <<'PY'
import zipfile, hashlib, os
for f in ["Chiron-Merriweather_v6.5.mtz",
          "Chiron-Merriweather_v6.5_AppleEmoji.mtz",
          "Chiron_KSU_Font_A17_v6.5.zip"]:
    if not os.path.exists(f): print("缺", f); continue
    print(f, os.path.getsize(f), hashlib.sha256(open(f,'rb').read()).hexdigest()[:16])
    with zipfile.ZipFile(f) as z:
        print("  ", len(z.namelist()), "entries", "testzip:", z.testzip() or "OK")
PY
```

| 检查 | 期望 |
|---|---|
| MTZ 里 `fonts/NotoColorEmoji.ttf` | 约 92 MB（Emoji 17.0 三档真彩） |
| KSU 里 `system/fonts/NotoColorEmoji.ttf` | 198,963,820 B（32/45/60/82/128 五档真彩） |
| MTZ 两个包里的 `Roboto-Regular.ttf` | 69,340,020 B（可变，`wght 150–700`，`usWeightClass=400`），两份一致 |
| KSU 里 `files/Roboto-Regular.ttf` | 28,111,052 B（静态 `wght=400`，默认不挂载） |
| MTZ `description.xml` 的 `<version>` | 6.7.1，与文件名一致；`<fontWeight>` 为 12 档 |
| KSU `module.prop` | `version=v6.7`、`versionCode=13` |
| `customize.sh` / `uninstall.sh` 的权限位 | `100755`（repack 脚本已保证） |

## 4. 打 tag 与发 Release

顺序很重要：**先改 `docs/release-notes.md` 并推 main，再打 tag**。CI 在 `push tags: v*`
时会用 `softprops/action-gh-release` + `body_path: docs/release-notes.md` 覆盖 Release 正文，
文件停在上一个版本，正文就会写成旧版本（v6.3 就是这么翻车的）。

```bash
git add -A
git commit -m "release: 6.7.1 —— MTZ 恢复字重可调；模块 6.7 修光标 / ZWJ / WebUI"
git push origin main

git tag -a v6.7.1 -m "v6.7.1"
git push origin v6.7.1
```

CI 会构建 APK 并创建 Release。字体成品体积超过仓库单文件 100 MB 的限制，只能手动挂到
Release 附件：Releases → 编辑 `v6.7.1` → 拖入 `Chiron_KSU_Font_A17_v6.7.zip` 与两个
`Chiron-Merriweather_v6.7.1*.mtz` → 正文用 `docs/release-notes.md` 的内容。

## 5. 真机验收

按顺序，每条都能从日志验证：

1. **MTZ**：主题商店装上后，设置里能看到 `Chiron Merriweather` 6.5；微信聊天框里 emoji 边缘不发灰
2. **新表情**：找一条 🫪 或 🪎 贴进备忘录，应该显示苹果那版图，不是豆腐块
3. **Root 模块**：`cat /data/adb/chiron_apple_emoji/post-fs.log`，应有 `stashed /data/fonts` 与 `bind OK`
4. **overlay 默认关**：没有 `enable_overlay` 文件时，日志是 `overlay fallback is OFF by default`
5. **可卸载**：卸载后 `pm list packages -d` 里不见 GMS 两个字体组件，`/data/adb/chiron_apple_emoji/disabled.list.done` 存在
6. **主题 emoji 还原**：`/data/system/theme/fonts/` 里的 emoji 与 `backup/…/theme-*` 的 sha256 一致
